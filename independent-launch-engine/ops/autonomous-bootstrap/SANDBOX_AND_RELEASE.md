# Ephemeral engineering sandbox + validation release policy
**Safe:** READ, DRAFT, reversible branch-write/preview only with verified tenant, writer lease, source SHA, zero unapproved provider spend.
**Protected:** production deployment, merge main, production DB/RLS, secrets, DNS, payments, real emails/messages, public social posts/replies, paid account provisioning, client remote access, destructive changes.
**Zones:** (0) Original immutable donor/approved visual, (1) disposable synthetic role-scoped Docker/worktree with no prod tokens/network by default, (2) authenticated tenant-scoped staging Vercel preview/DB with independent Guardian reviewer.
**Job:** INGEST -> SOURCE_LOCK -> TENANT/AUTH -> LEASE -> SANDBOX BUILD -> BROWSER QA -> FAULT INJECTION -> INDEPENDENT REVIEW -> RECEIPT -> OWNER RELEASE APPROVAL -> MONITOR.
**Limits by default:** cost 0, max 2 repairs, no production API tokens, immutable packet and idempotency, lease expiry, kill switch, activity receipts; do not create per-client crons or per-customer Supabase projects without independently justified isolation.
**Three-pass gate:** three distinct full browser sessions with same deployment ID and SHA: desktop 1440x900 + mobile 390x844, every button/navigation/form, auth and cross-tenant denied access, privacy, accessibility, load/perf, deliberate faults only in sandboxes, rollback. An HTTP 200/build/test plan is NOT one PASS.
**Client OS standard:** every site includes client owner auth and portal, CRM/lead inbox, analytics, digital card, media, social draft/approval studio, SEO/content monitors and owner-controlled AI assistance. External social publication and replies need channel-specific signed consent.
**Completion email/video/warranty:** draft first; sending or publishing requires verified release URL, owner authorization, approved terms/assets and delivery receipts. Cannot claim a finished product when unfinished.
**Known P0 blockers:** two estate reconciler processes; local worker's packet-only build handler; weak AutoComplete tenant test; previously seen X1 CONTROL_PLANE_AUTHORIZATION_FAILED; RLS-disabled tables; real autonomous coding/tenant browser QA not yet proven.
